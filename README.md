## 📚 เกี่ยวกับหลักสูตร

หลักสูตรนี้ออกแบบมาเพื่อพาคุณจากระดับ **มือใหม่** ไปสู่ระดับ **มืออาชีพ** และ **ระดับโลก** ในการพัฒนาโปรแกรมและเว็บแอพพลิเคชันด้วย LINE Official Account

### LINE OA คืออะไร?

**LINE Official Account (LINE OA)** คือ บัญชีไลน์สำหรับธุรกิจ แบรนด์ หรือองค์กร ที่ช่วยให้คุณสามารถ:
- สื่อสารกับลูกค้าจำนวนมากได้อย่างมีประสิทธิภาพ
- ทำการตลาดผ่านแพลตฟอร์มที่คนไทยใช้มากที่สุด
- พัฒนาแอพพลิเคชันและบอทที่ทรงพลัง
- สร้างประสบการณ์ลูกค้าที่เป็นเลิศ

## 🛠️ เครื่องมือที่ต้องการ

### สำหรับผู้เริ่มต้น (Parts 1-20)
- Browser (Chrome recommended)
- LINE App บนมือถือ
- LINE OA Account (สมัครได้ฟรี)

### สำหรับระดับกลาง (Parts 21-40)
- Node.js 18+ หรือ Python 3.9+ หรือ PHP 8.0+
- VS Code หรือ IDE ที่ชื่นชอบ
- Git & GitHub account
- Ngrok (สำหรับ local development)
- Postman หรือ Insomnia

### สำหรับระดับสูง (Parts 41-80)
- Docker Desktop
- Database: MySQL/PostgreSQL/MongoDB/Redis
- Cloud Platform: AWS/GCP/Azure
- LINE Developer Console access

### สำหรับระดับโลก (Parts 81-100)
- Kubernetes cluster
- CI/CD tools (GitHub Actions, Jenkins)
- Monitoring: Prometheus, Grafana
- Log management: ELK Stack
