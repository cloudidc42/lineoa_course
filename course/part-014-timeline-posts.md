# Part 14: Timeline Posts - กลยุทธ์ Content บน LINE OA

## บทนำ

LINE OA Timeline เป็นช่องทางที่มักถูกมองข้ามแต่มีความสำคัญอย่างยิ่งในการสร้าง Brand Awareness และ Organic Reach ต่างจากการ Broadcast ที่ส่งตรงถึง Chat Timeline เป็น Feed ที่ผู้ใช้ติดตาม OA ของคุณสามารถเห็นได้เมื่อเปิด LINE ในแท็บ VOOM บทนี้จะสอนวิธีสร้าง Content ที่น่าสนใจ กำหนดเวลาโพสต์อย่างมีกลยุทธ์ และวิเคราะห์ผลลัพธ์

## 14.1 LINE OA Timeline vs Broadcast

### ความแตกต่างพื้นฐาน

| คุณสมบัติ | Timeline Post | Broadcast Message |
|-----------|--------------|-------------------|
| ช่องทาง | LINE VOOM Tab | Chat |
| ค่าใช้จ่าย | ฟรี | ใช้ Message Quota |
| การเข้าถึง | Organic + Boost | ส่งถึงทุกคน |
| Engagement | Like, Comment, Share | Reply เท่านั้น |
| Shelf Life | คงอยู่ใน Feed | หายเมื่อเลื่อนลง |
| Algorithm | มีการ Filter | ไม่ Filter |
| ประเภทเนื้อหา | Social Content | Transactional/Promo |
| Target Audience | ผู้ติดตาม OA | ผู้ที่เพิ่ม OA เป็นเพื่อน |

### เมื่อไหร่ควรใช้อะไร

**ใช้ Timeline Post เมื่อ:**
- ต้องการสร้าง Brand Awareness
- แชร์เนื้อหาที่ให้ประโยชน์ (Tips, How-to)
- แสดงผลงาน (Testimonials, Before/After)
- บอกเล่าเรื่องราวแบรนด์
- ไม่ต้องการเสีย Message Quota

**ใช้ Broadcast เมื่อ:**
- โปรโมชั่นสำคัญที่ต้องแจ้งทันที
- ส่ง Coupon หรือ Reward
- ข่าวสารด่วน
- วันนัดหมายหรือ Event ที่ใกล้ถึง

### 14.2.1 ประเภทของ Timeline Post

| ประเภท | คำอธิบาย | เหมาะกับ |

### 14.2.2 วิธีสร้าง Timeline Post ใน LINE OA Manager

#### ขั้นตอนสำหรับ Photo Post

```
1. เข้า LINE OA Manager (manager.line.biz)
2. คลิก "Timeline" ในเมนูซ้าย
3. คลิก "+ Create Post"
4. เลือกประเภท "Photo"
5. อัปโหลดภาพ (สูงสุด 10 รูป):
   - คลิก "+ Add Photo"
   - เลือกไฟล์จากคอมพิวเตอร์
   - จัดเรียงลำดับตามต้องการ
6. เขียนข้อความ Caption:
   - สูงสุด 2,000 ตัวอักษร
   - ใส่ Hashtag (#) ได้
   - ใส่ @mention ได้
7. เลือก:
   □ โพสต์ทันที
   □ กำหนดเวลา
8. คลิก "Post" หรือ "Schedule"
```

```python
# ตัวอย่าง Content Calendar Python Script

from datetime import datetime, timedelta
import calendar

def create_monthly_content_calendar(month, year, business_type):
    """
    สร้าง Content Calendar รายเดือน
    
    Args:
        month: เดือน (1-12)
        year: ปี
        business_type: ประเภทธุรกิจ
    
    Returns:
        List ของ Post Schedule
    """
    
    content_themes = {
        "restaurant": {
            "Monday": {"theme": "เมนูพิเศษสัปดาห์", "type": "photo", "hashtags": ["#เมนูใหม่", "#อาหารอร่อย"]},
            "Wednesday": {"theme": "เบื้องหลังครัว", "type": "video", "hashtags": ["#behindthescenes", "#ร้านอาหาร"]},
            "Friday": {"theme": "Weekend Special", "type": "photo", "hashtags": ["#weekend", "#โปรโมชั่น"]},
            "Saturday": {"theme": "Customer Review", "type": "photo", "hashtags": ["#review", "#อาหารดี"]},
            "Sunday": {"theme": "Quote/Inspiration", "type": "text", "hashtags": ["#inspiration", "#อาหาร"]}
        },
        "retail": {
            "Monday": {"theme": "New Arrivals", "type": "photo", "hashtags": ["#newarrival", "#สินค้าใหม่"]},
            "Tuesday": {"theme": "Style Tips", "type": "photo", "hashtags": ["#tips", "#แฟชั่น"]},
            "Thursday": {"theme": "Lookbook", "type": "photo", "hashtags": ["#lookbook", "#outfit"]},
            "Friday": {"theme": "Flash Sale", "type": "photo", "hashtags": ["#sale", "#ลดราคา"]},
            "Saturday": {"theme": "OOTD Customer", "type": "photo", "hashtags": ["#OOTD", "#customer"]}
        },
        "beauty": {
            "Monday": {"theme": "Skincare Tips", "type": "text", "hashtags": ["#skintips", "#ดูแลผิว"]},
            "Wednesday": {"theme": "Before & After", "type": "photo", "hashtags": ["#beforeafter", "#ผลลัพธ์"]},
            "Friday": {"theme": "Treatment Intro", "type": "video", "hashtags": ["#treatment", "#beauty"]},
            "Saturday": {"theme": "Promotion", "type": "photo", "hashtags": ["#promo", "#ราคาพิเศษ"]}
        }
    }
    
    theme_set = content_themes.get(business_type, content_themes["retail"])
    
    calendar_plan = []
    
    # วนทุกวันในเดือน
    days_in_month = calendar.monthrange(year, month)[1]
    
    for day in range(1, days_in_month + 1):
        date = datetime(year, month, day)
        day_name = date.strftime("%A")
        
        if day_name in theme_set:
            theme = theme_set[day_name]
            
            # กำหนดเวลาที่ดีที่สุด
            post_time = "12:00" if day_name in ["Monday", "Wednesday"] else "18:00"
            if day_name in ["Saturday", "Sunday"]:
                post_time = "10:00"
            
            calendar_plan.append({
                "date": date.strftime("%Y-%m-%d"),
                "day": day_name,
                "time": post_time,
                "theme": theme["theme"],
                "content_type": theme["type"],
                "hashtags": theme["hashtags"],
                "status": "planned"
            })
    
    return calendar_plan

# ใช้งาน
```

## 14.5 Timeline Post Analytics

### Metrics ที่สำคัญ

| Metric | คำอธิบาย | เป้าหมาย |
|--------|----------|----------|
| Impressions | จำนวนครั้งที่เห็น Post | ยิ่งมากยิ่งดี |
| Reach | จำนวนคนที่เห็น (Unique) | > 5% ของ Followers |
| Likes | จำนวน Like | > 2% ของ Reach |
| Comments | จำนวน Comment | > 0.5% ของ Reach |
| Shares | จำนวน Share | > 0.3% ของ Reach |
| Engagement Rate | (Like+Comment+Share)/Reach | > 3% |

### การดู Analytics ใน LINE OA Manager

```
1. เข้า LINE OA Manager
2. คลิก "Insight" > "Timeline"
3. เลือกช่วงเวลาที่ต้องการดู
4. ดูข้อมูล:
   - Impressions per Post
   - Engagement Rate
   - Best Performing Posts
   - Follower Growth
   - Peak Time ที่ Post Perform ดีสุด
```

### การวิเคราะห์ด้วย Python

```python
def analyze_timeline_performance(posts_data):
    """
    วิเคราะห์ Performance ของ Timeline Posts
    """
    
    analytics = []
    
    for post in posts_data:
        reach = post.get("reach", 0)
        
        if reach == 0:
            continue
        
        # คำนวณ Metrics
        engagement_rate = (
            post.get("likes", 0) + 
            post.get("comments", 0) + 
            post.get("shares", 0)
        ) / reach * 100
        
        # ประเมินประสิทธิภาพ
        if engagement_rate >= 5:
            performance = "ดีมาก"
        elif engagement_rate >= 3:
            performance = "ดี"
        elif engagement_rate >= 1:
            performance = "พอใช้"
        else:
            performance = "ต้องปรับปรุง"
        
        analytics.append({
            "post_id": post["id"],
            "date": post["created_at"],
            "content_type": post.get("type", "photo"),
            "reach": reach,
            "impressions": post.get("impressions", 0),
            "likes": post.get("likes", 0),
            "comments": post.get("comments", 0),
            "shares": post.get("shares", 0),
            "engagement_rate": round(engagement_rate, 2),
            "performance": performance
        })
    
    # หา Best Performing Posts
    sorted_by_engagement = sorted(analytics, key=lambda x: x["engagement_rate"], reverse=True)
    
    # สรุปภาพรวม
    if analytics:
        avg_engagement = sum(p["engagement_rate"] for p in analytics) / len(analytics)
        best_day = _find_best_day(analytics)
        best_content_type = _find_best_content_type(analytics)
        
        summary = {
            "total_posts": len(analytics),
            "avg_engagement_rate": round(avg_engagement, 2),
            "best_performing_post": sorted_by_engagement[0] if sorted_by_engagement else None,
            "best_day_to_post": best_day,
            "best_content_type": best_content_type,
            "recommendations": _generate_timeline_recommendations(analytics)
        }
    else:
        summary = {"total_posts": 0}
    
    return {
        "posts": analytics,
        "summary": summary,
        "top_posts": sorted_by_engagement[:5]
    }

def _find_best_day(analytics):
    """หาวันที่ Engagement ดีสุด"""
    from datetime import datetime
    
    day_engagement = {}
    
    for post in analytics:
        try:
            date = datetime.fromisoformat(post["date"])
            day = date.strftime("%A")
            
            if day not in day_engagement:
                day_engagement[day] = []
            day_engagement[day].append(post["engagement_rate"])
        except:
            continue
    
    if not day_engagement:
        return "N/A"
    
    avg_by_day = {
        day: sum(rates) / len(rates) 
        for day, rates in day_engagement.items()
    }
    
    return max(avg_by_day, key=avg_by_day.get)

def _find_best_content_type(analytics):
    """หา Content Type ที่ Perform ดีสุด"""
    type_engagement = {}
    
    for post in analytics:
        content_type = post.get("content_type", "unknown")
        
        if content_type not in type_engagement:
            type_engagement[content_type] = []
        type_engagement[content_type].append(post["engagement_rate"])
    
    if not type_engagement:
        return "N/A"
    
    avg_by_type = {
        t: sum(rates) / len(rates) 
        for t, rates in type_engagement.items()
    }
    
    return max(avg_by_type, key=avg_by_type.get)

def _generate_timeline_recommendations(analytics):
    """สร้างคำแนะนำจาก Analytics"""
    
    recommendations = []
    avg_engagement = sum(p["engagement_rate"] for p in analytics) / len(analytics)
    
    if avg_engagement < 2:
        recommendations.append("ลองเพิ่มความถี่การโพสต์เป็น 5-7 ครั้งต่อสัปดาห์")
        recommendations.append("ทดลอง Content Type ใหม่ เช่น วิดีโอหรือ Behind the Scenes")
    
    video_posts = [p for p in analytics if p.get("content_type") == "video"]
    photo_posts = [p for p in analytics if p.get("content_type") == "photo"]
    
    if video_posts and photo_posts:
        avg_video = sum(p["engagement_rate"] for p in video_posts) / len(video_posts)
        avg_photo = sum(p["engagement_rate"] for p in photo_posts) / len(photo_posts)
        
        if avg_video > avg_photo * 1.5:
            recommendations.append(f"วิดีโอ Engage ดีกว่ารูป {avg_video/avg_photo:.1f}x ลองเพิ่มสัดส่วนวิดีโอ")
    
    return recommendations
```

### การนำ Content ไปใช้หลายช่องทาง

```
LINE OA Timeline ➡️ TikTok (ปรับรูปแบบ)
LINE OA Timeline ➡️ Broadcast (เลือกเฉพาะที่สำคัญ)
```

### Adaptation Matrix

| Content | LINE Timeline | Facebook | Instagram | TikTok |
|---------|-------------|---------|---------|--------|
| Photo | ✓ 1:1 หรือ 4:3 | ✓ 4:5 | ✓ 1:1 | ✗ |
| Video | ✓ 16:9 | ✓ 16:9 | ✓ Reels 9:16 | ✓ 9:16 |
| Text | ✓ | ✓ | Caption เท่านั้น | Caption เท่านั้น |
| Story | ✗ | ✓ | ✓ | ✓ |

### Python Script สำหรับ Cross-Posting

```python
class CrossPostingManager:
    """
    จัดการ Cross-posting ระหว่างแพลตฟอร์ม
    """
    
    def __init__(self, credentials):
        self.line_token = credentials.get("line_access_token")
        # สามารถเพิ่ม Facebook, Instagram API ได้
    
    def adapt_content_for_platform(self, original_content, platform):
        """
        ปรับ Content ให้เหมาะกับแต่ละแพลตฟอร์ม
        """
        
        adapted = original_content.copy()
        
        if platform == "line_timeline":
            # LINE: เต็มรูปแบบ
            adapted["max_caption_length"] = 2000
            adapted["hashtag_count"] = 5
            adapted["image_ratio"] = "1:1"
            
        elif platform == "facebook":
            # Facebook: เน้นข้อมูลและ Link
            adapted["max_caption_length"] = 63206
            adapted["hashtag_count"] = 3
            adapted["add_link"] = True
            
        elif platform == "instagram":
            # Instagram: เน้นภาพ + Hashtag
            adapted["max_caption_length"] = 2200
            adapted["hashtag_count"] = 30
            adapted["image_ratio"] = "1:1"
            
        return adapted
    
    def post_to_line_timeline(self, content):
        """
        โพสต์ไปยัง LINE OA Timeline
        ผ่าน LINE Messaging API
        """
        
        # LINE Messaging API ไม่รองรับการโพสต์ Timeline โดยตรง
        # ต้องใช้ LINE OA Manager หรือ LINE Official Account API
        
        # แต่สามารถส่ง Broadcast เพื่อแจ้งเตือนว่ามี Post ใหม่
        import requests
        
        message = {
            "type": "text",
            "text": f"📢 มีโพสต์ใหม่บน Timeline!\n\n{content.get('caption', '')[:100]}...\n\n👆 ดูโพสต์เต็มๆ ได้เลยค่ะ"
        }
        
        # Broadcast notification
        requests.post(
            "https://api.line.me/v2/bot/message/broadcast",
            headers={
                "Authorization": f"Bearer {self.line_token}",
                "Content-Type": "application/json"
            },
            json={"messages": [message]}
        )
```

## 14.8 Paid Timeline Boost

### ภาพรวม LINE Timeline Boost

LINE OA ให้บริการ Boost หรือ Sponsored Post เพื่อเพิ่ม Reach ให้กับ Timeline Post

### การตั้งค่า Boost Post

```
1. เลือก Post ที่ต้องการ Boost
2. คลิก "Boost Post"
3. กำหนด:
   - งบประมาณ: ขั้นต่ำ ฿50/วัน
   - ระยะเวลา: 1-90 วัน
   - กลุ่มเป้าหมาย:
     * ผู้ติดตาม OA
     * เพื่อนของผู้ติดตาม
     * กลุ่มเฉพาะ (ตาม Demographics)
4. ตรวจสอบ Estimated Reach
5. ยืนยันการ Boost
```

### การประเมินผล Boost Campaign

| Metric | คำอธิบาย | เป้าหมาย |
|--------|----------|----------|
| Cost per Reach | งบ / จำนวนคนที่เห็น | < ฿0.50 |
| Cost per Engagement | งบ / จำนวน Engagement | < ฿2.00 |
| Cost per Click | งบ / จำนวน Click | < ฿5.00 |
| ROAS | Revenue / Ad Spend | > 3x |

```python
def calculate_boost_roi(boost_data):
    """
    คำนวณ ROI ของ Timeline Boost
    """
    
    budget = boost_data.get("budget", 0)
    reach = boost_data.get("reach", 0)
    clicks = boost_data.get("clicks", 0)
    conversions = boost_data.get("conversions", 0)
    revenue = boost_data.get("revenue_from_boost", 0)
    
    metrics = {
        "cost_per_reach": budget / reach if reach > 0 else 0,
        "cost_per_click": budget / clicks if clicks > 0 else 0,
        "cost_per_conversion": budget / conversions if conversions > 0 else 0,
        "roas": revenue / budget if budget > 0 else 0,
        "ctr": clicks / reach * 100 if reach > 0 else 0,
        "conversion_rate": conversions / clicks * 100 if clicks > 0 else 0
    }
    
    # ประเมินผล
    if metrics["roas"] >= 3:
        verdict = "คุ้มค่ามาก - ควร Scale Up"
    elif metrics["roas"] >= 2:
        verdict = "คุ้มค่า - ดำเนินต่อ"
    elif metrics["roas"] >= 1:
        verdict = "เฉือนกำไรนิดหน่อย - ต้องปรับ"
    else:
        verdict = "ขาดทุน - หยุดและปรับกลยุทธ์"
    
    return {**metrics, "verdict": verdict}

# ตัวอย่าง
boost_result = calculate_boost_roi({
    "budget": 500,
    "reach": 5000,
    "clicks": 300,
    "conversions": 15,
    "revenue_from_boost": 2250
})
print(f"ROAS: {boost_result['roas']:.1f}x")
print(f"Verdict: {boost_result['verdict']}")
```
