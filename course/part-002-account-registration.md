## 1. เตรียมตัวก่อนสมัคร

### 1.1 สิ่งที่ต้องมีก่อนสมัคร

ก่อนเริ่มสมัคร LINE OA ให้เตรียมสิ่งต่อไปนี้:

```
Checklist ก่อนสมัคร LINE OA:
════════════════════════════════════════

บัญชีส่วนตัว:
[✓] บัญชี LINE ส่วนตัวที่ Active
[✓] หมายเลขโทรศัพท์ที่ผูกกับ LINE
[✓] Email Address ที่ใช้งานได้

สำหรับธุรกิจ:
[✓] ชื่อธุรกิจ/แบรนด์ (ภาษาไทยหรืออังกฤษ)
[✓] ประเภทธุรกิจ
[✓] รูปโปรไฟล์ (400x400 px ขึ้นไป)
[✓] รูป Cover Photo (1080x878 px แนะนำ)

สำหรับ Verification (ถ้าต้องการ):
[✓] เอกสารจดทะเบียนธุรกิจ (หากมี)
[✓] บัตรประชาชนหรือ Passport
[✓] Website ของธุรกิจ (หากมี)

════════════════════════════════════════
```

### 1.2 ข้อกำหนดพื้นฐาน

> **⚠️ สำคัญ:** LINE OA ต้องเชื่อมกับบัญชี LINE ส่วนตัว ไม่สามารถสร้างได้โดยไม่มีบัญชีส่วนตัว

**ข้อกำหนด:**
- อายุ 18 ปีขึ้นไป (สำหรับการยืนยันบัญชีธุรกิจ)
- มีหมายเลขโทรศัพท์ที่ยืนยันได้
- ยอมรับ Terms of Service ของ LINE

### 1.3 ความแตกต่างของการสมัครผ่านช่องทางต่างๆ

| ช่องทาง | ลิงก์ | ข้อดี | ข้อเสีย |
|---------|------|------|---------|
| Browser (Desktop) | manager.line.biz | สะดวก ทำได้ง่าย | - |
| LINE App (Mobile) | ใน App LINE | ทำบน Mobile ได้ | หน้าจอเล็ก |
| LINE OA App | App แยก | จัดการได้ดี | ต้องดาวน์โหลด App |

## 2. ขั้นตอนการสมัครบัญชี LINE OA

### 2.1 สมัครผ่าน Browser (แนะนำ)

#### ขั้นตอนที่ 1: เข้าเว็บไซต์

```
1. เปิด Browser (Chrome, Firefox, Safari)
2. ไปที่: https://account.line.biz/login
3. คลิก "Log in with LINE"
```

```
หน้าจอที่จะเห็น:
┌─────────────────────────────────────────┐
│         LINE Official Account           │
│                                         │

│   └─────────────────────────────────┘   │
│                                         │
│   ┌─────────────────────────────────┐   │
│   │  Email  [___________________]   │   │
│   │  Password [___________________] │   │
│   │  [ Log in ]                     │   │
│   └─────────────────────────────────┘   │
└─────────────────────────────────────────┘
```

#### ขั้นตอนที่ 2: Login ด้วย LINE Account

**วิธีที่ 1: QR Code**
```
1. เปิด LINE App บนมือถือ
2. กด [...] มุมบนขวา
3. กด [QR Code]
4. สแกน QR Code ที่หน้าจอ
5. กด [Log in] บนมือถือ
```

**วิธีที่ 2: Email/Password**
```
1. กรอก Email ที่ผูกกับ LINE
2. กรอก Password
3. กด [Log in]
4. ยืนยัน OTP ที่ส่งไปยังมือถือ
```

#### ขั้นตอนที่ 3: สร้างบัญชีใหม่

หลัง Login จะเข้าสู่หน้า Dashboard ให้ทำตามนี้:

```
1. คลิก "Create" หรือ "สร้าง" (มุมบนขวา)
2. เลือก "Create a LINE Official Account"
```

#### ขั้นตอนที่ 4: ยืนยัน Email

```
1. ระบบจะส่ง Email ยืนยันไปยัง Email ที่กรอก
2. เปิด Email และคลิก "Verify Email"
3. กลับมาที่หน้า Manager และ Refresh
```

> **📧 ตรวจสอบ Spam Folder:** บางครั้ง Email ยืนยันอาจตกไปอยู่ใน Spam หรือ Junk Mail

#### ขั้นตอนที่ 5: ตั้งค่าข้อมูลธุรกิจ

หลังยืนยัน Email แล้ว ระบบจะให้กรอกข้อมูลธุรกิจ:

```

│   เช่น: Food & Beverage, Retail, Service, etc.
├── URL ของเว็บไซต์ (ถ้ามี)
├── หมายเลขโทรศัพท์ธุรกิจ
└── ที่อยู่ธุรกิจ
```

## 3. เอกสารที่จำเป็น

### 3.1 สำหรับบัญชีทั่วไป (ไม่ Verify)

ไม่ต้องใช้เอกสารใดๆ เพียงมีบัญชี LINE ส่วนตัวก็สมัครได้

### 3.2 สำหรับการ Verify เป็น Blue Shield

**เอกสารสำหรับบุคคลธรรมดา:**
```
1. บัตรประชาชน (ถ่ายภาพหน้า-หลัง)
2. หนังสือมอบอำนาจ (ถ้ามีผู้ดำเนินการแทน)
3. เอกสารแสดงความเป็นเจ้าของธุรกิจ (ถ้ามี)
```

**เอกสารสำหรับนิติบุคคล:**
```
1. หนังสือรับรองจากกรมพัฒนาธุรกิจการค้า (DBD)
   - อายุไม่เกิน 6 เดือน
2. บัตรประชาชนของกรรมการผู้มีอำนาจ
3. เอกสาร BOJ.5 (รายชื่อกรรมการ)
4. หนังสือมอบอำนาจ (ถ้าไม่ใช่กรรมการยื่นเอง)
```

### 3.3 รูปแบบไฟล์เอกสารที่ยอมรับ

| ประเภทไฟล์ | ขนาดสูงสุด | รูปแบบ |
|-----------|---------|--------|
| รูปภาพ | 10 MB | JPG, PNG |
| PDF | 10 MB | PDF |
| ความละเอียด | - | อ่านออกได้ชัดเจน |

> **📝 เคล็ดลับ:** ใช้แอปสแกนเอกสาร เช่น CamScanner หรือ Adobe Scan เพื่อให้ได้ภาพที่คมชัดและอ่านได้ง่าย

### 3.4 ระยะเวลาการตรวจสอบเอกสาร

```
Timeline การตรวจสอบเอกสาร:
──────────────────────────────────────
ส่งเอกสาร
    │
    ▼
LINE ตรวจสอบ (3-5 วันทำการ)
    │
    ├── ✓ ผ่าน → ได้รับ Blue Shield
    │
    └── ✗ ไม่ผ่าน → รับ Email แจ้งสาเหตุ
                      ต้องส่งเอกสารใหม่
──────────────────────────────────────
```

## 4. กระบวนการยืนยันบัญชี (Verification)

### 4.1 ขั้นตอนขอ Verify Blue Shield

```
ขั้นตอนการขอ Verification:

ขั้นที่ 1: เข้า LINE OA Manager
  → Settings → Account Info → Verification

ขั้นที่ 2: เลือกประเภทการ Verify
  → บุคคลธรรมดา หรือ นิติบุคคล

ขั้นที่ 3: กรอกข้อมูลธุรกิจ
  → ชื่อ, ที่อยู่, ประเภทธุรกิจ

ขั้นที่ 4: อัปโหลดเอกสาร
  → ตามประเภทที่เลือก

ขั้นที่ 5: รอการตรวจสอบ
  → 3-14 วันทำการ

ขั้นที่ 6: รับผลการพิจารณา
  → ทาง Email ที่ลงทะเบียน
```

### 4.2 เหตุผลที่ Verification ถูกปฏิเสธบ่อยๆ

| เหตุผล | วิธีแก้ไข |
|--------|----------|
| เอกสารไม่ชัดเจน | ถ่ายภาพใหม่ในที่แสงสว่างเพียงพอ |
| เอกสารหมดอายุ | ใช้เอกสารที่อัปเดตล่าสุด |
| ชื่อธุรกิจไม่ตรงกับเอกสาร | ใช้ชื่อเดียวกันกับจดทะเบียน |
| ไม่ได้แนบเอกสารครบ | ตรวจสอบ Checklist ก่อนส่ง |
| ประเภทธุรกิจไม่เหมาะสม | ติดต่อ LINE Support |

### 4.3 การติดตามสถานะ Verification

```
เช็คสถานะได้ที่:
LINE OA Manager → Settings → Account Info → Verification Status

สถานะที่เป็นไปได้:
- Pending Review (กำลังตรวจสอบ)
- Documents Required (ต้องส่งเอกสารเพิ่ม)
- Under Review (อยู่ระหว่างพิจารณา)
- Approved (อนุมัติแล้ว ✓)
- Rejected (ไม่อนุมัติ ✗)
```

### 5.3 ตั้งค่า Basic ID และ Premium ID

**Basic ID (ฟรี):**
- รูปแบบ: @ตัวอักษรและตัวเลขที่ระบบสร้างให้
- ตัวอย่าง: @abc123xyz
- ใช้สำหรับ Add เป็นเพื่อน: line.me/R/ti/p/@abc123xyz

**Premium ID (มีค่าใช้จ่าย):**
- รูปแบบ: @ชื่อที่คุณต้องการ
- ตัวอย่าง: @fashionshop
- ค่าใช้จ่าย: ~1,500 บาท/ปี
- ต้องซื้อผ่าน LINE OA Manager

```
ขั้นตอนซื้อ Premium ID:
1. Settings → LINE ID
2. คลิก "Purchase a Premium ID"
3. กรอก ID ที่ต้องการ
4. ตรวจสอบว่าว่างอยู่
5. ชำระเงิน
6. ID จะ Active ทันที
```

```
🛒 สั่งซื้อสินค้า
📱 ติดตามออเดอร์

```

## 6. ปัญหาที่พบบ่อยและวิธีแก้ไข

### 6.1 ปัญหา: Login ไม่ได้

**อาการ:** กด "Log in with LINE" แต่ไม่สำเร็จ

```
วิธีแก้ไข:

ปัญหา A: QR Code หมดอายุ
  → Refresh หน้าเว็บและ Scan QR ใหม่

ปัญหา B: LINE App ไม่อัปเดต
  → อัปเดต LINE App เป็นเวอร์ชันล่าสุด

ปัญหา C: 2-Step Verification
  → ยืนยัน OTP ที่ส่งมาทาง SMS

ปัญหา D: บัญชีถูก Lock
  → ติดต่อ LINE Support: https://help.line.me
```

### 6.2 ปัญหา: ไม่ได้รับ Email ยืนยัน

```
วิธีแก้ไข:

1. ตรวจสอบ Spam/Junk Mail
2. รอ 5-10 นาที แล้วตรวจใหม่
3. กด "Resend verification email"
   (อยู่ในหน้า Manager)
4. ตรวจสอบว่า Email ถูกต้อง
5. ลองใช้ Email อื่น
6. ติดต่อ support@linecorp.com
```

### 6.3 ปัญหา: ชื่อ LINE OA ที่ต้องการถูกใช้แล้ว

```
วิธีแก้ไข:

1. เพิ่มตัวอักษรต่อท้าย:
   "ร้านขนมไทย" → "ร้านขนมไทยแท้"

2. เพิ่มชื่อเมือง:
   "Fashion Shop" → "Fashion Shop กรุงเทพ"

3. เพิ่มปีที่ก่อตั้ง:
   "ABC Bakery" → "ABC Bakery 2020"

4. ใช้ชื่อย่อหรือชื่อเล่น:
   "บริษัทขนมไทยจำกัด" → "ขนมไทยแบรนด์"
```

### 6.4 ปัญหา: ไม่สามารถอัปโหลดรูปโปรไฟล์

```
สาเหตุที่เป็นไปได้:

1. ไฟล์ใหญ่เกินไป
   → ลดขนาดไฟล์ให้ต่ำกว่า 10 MB
   → ใช้ TinyPNG.com หรือ Squoosh.app

2. รูปแบบไฟล์ไม่รองรับ
   → ใช้ JPG หรือ PNG เท่านั้น
   → แปลงจาก HEIC เป็น JPG บน iPhone

3. รูปมี Inappropriate Content
   → ใช้รูปที่เหมาะสม ไม่มีเนื้อหา 18+

4. Browser Cache ค้าง
   → ล้าง Cache หรือใช้ Incognito Mode
```

### 6.5 ปัญหา: Verification ถูกปฏิเสธซ้ำๆ

```
ขั้นตอนแก้ไข:

1. อ่าน Email แจ้งสาเหตุอย่างละเอียด

2. แก้ไขตาม Reason ที่ระบุ:

   "Documents not clear" 
   → ถ่ายเอกสารใหม่ในที่แสงสว่าง
   → ตรวจสอบว่าอ่านออกทุกตัวอักษร

   "Business name mismatch"
   → ให้ชื่อ LINE OA ตรงกับเอกสารจดทะเบียน

   "Expired documents"
   → ขอเอกสารใหม่จากกรมพัฒนาธุรกิจ

3. หาก Reject 3 ครั้ง ติดต่อ LINE Support
   → https://account.line.biz/support
```

## 8. Security และ Best Practices

### 8.1 การรักษาความปลอดภัยบัญชี

```
Security Checklist:

[ ] เปิด 2-Step Verification บน LINE Account
[ ] ใช้ Password ที่แข็งแกร่ง (ตัวอักษร+ตัวเลข+สัญลักษณ์)
[ ] ไม่แชร์ Login Credentials กับผู้อื่น
[ ] ใช้ระบบ Admin เพื่อแชร์สิทธิ์แทน
[ ] ตรวจสอบ Admin List เป็นประจำ
[ ] Log out หลังใช้งานบน Shared Computer
[ ] ระวัง Phishing (เว็บปลอม)
```

### 8.2 การเปิด 2-Step Verification

```
ขั้นตอน:
1. เปิด LINE App บนมือถือ
2. ไป Settings → Account → 2-Step Verification
3. กด "Turn On"
4. ยืนยันเบอร์โทรศัพท์
5. ทดสอบ Login ใหม่
```

### 8.3 สิ่งที่ไม่ควรทำ

```
❌ ห้ามทำ:
- ไม่แชร์ Channel Access Token กับผู้อื่น
- ไม่โพสต์ Credentials บน GitHub หรือ Social Media
- ไม่ใช้ Password เดียวกันกับหลายบริการ
- ไม่คลิก Link ใน Email ที่ดูน่าสงสัย
- ไม่อนุญาตให้ App ไม่รู้จักเข้าถึงบัญชี
```

### 8.4 การ Backup ข้อมูลสำคัญ

```
ข้อมูลที่ควร Backup:
├── Channel ID และ Channel Secret
├── Long-lived Access Token
├── Rich Menu Template
├── Broadcast ที่สำคัญ
└── รายชื่อ Admin

วิธี Export ข้อมูล:
Analytics → Export → CSV
(สามารถ Export สถิติเป็น CSV ได้)
```
